# Lab 0 — Environment Orientation

| | |
|---|---|
| Level | All (mandatory before Labs 1–4) |
| Time | 30–45 minutes |
| Pattern | A: offline workstation, no network |
| Version | 0.1.0 |
| Tested on | Linux x86-64, 2026-10-09, substitute Ubuntu 24.04 base (13/13 integration checks). **macOS, Windows, arm64, Debian 13 base: UNTESTED** |

**Students:** start with the [student guide](docs/student-guide.md).

**Quick reference**
```bash
docker compose pull                 # download the image
docker compose run --rm verify      # check your environment
docker compose run --rm reset       # fresh answer templates in work/
docker compose run --rm workstation # analyst shell
docker compose down --remove-orphans
```

**Maintainers:** evidence is generated by `scripts/build_evidence.py` (deterministic; tests enforce that the committed copy matches). The answer key is in the private instructor repository.
