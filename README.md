# CyberLab — Containerized Cybersecurity & Digital Forensics Laboratories

A reusable, security-hardened platform of hands-on laboratories for undergraduate and early-graduate cybersecurity and digital forensics courses, built on Docker and Docker Compose, with seeded synthetic evidence and reproducible grading.

> **Project status: Phase 1 (requirements & feasibility).** No lab is implemented yet. Nothing in this repository has been classroom-tested.

| Lab | Topic | Audience | Status |
|---|---|---|---|
| 0 | Environment orientation (Docker, Linux shell, hashing) | All | Planned — Milestone 1 |
| 1 | Network Traffic Analysis & Threat Identification | Intro UG | Planned — MVP |
| 2 | Linux File-System Forensics & Evidence Examination | Intermediate UG | Planned |
| 3 | Web Application Security Assessment | Upper UG | Planned |
| 4 | Incident Response & Multi-Source Digital Forensics | Early graduate | Planned |

**Start here:** [docs/phase-1/README.md](docs/phase-1/README.md)

All evidence is synthetic. All labs are isolated sandboxes for authorized educational use only.
