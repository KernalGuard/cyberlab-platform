## CyberLab v0.2.0 — Lab 1: Network Traffic Analysis

**Pilot preview.** Lab 1 is complete and tested in CI and on macOS. It has not yet been used in a class.

### For students
- New lab: [Lab 1 — Network Traffic Analysis and Threat Identification](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab1-network-traffic/docs/student-guide.md). Investigate an hour of traffic from a fictional nonprofit, find the compromised workstation, its command-and-control channel and what data left the network, using TShark in an isolated container.
- Complete [Lab 0](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab0-orientation/docs/student-guide.md) first.

```bash
git clone https://github.com/KernalGuard/cyberlab-platform.git
cd cyberlab-platform/labs/lab1-network-traffic
docker compose pull
docker compose run --rm verify
```
