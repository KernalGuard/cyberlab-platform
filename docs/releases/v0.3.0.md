## CyberLab v0.3.0 — Lab 2: Linux File-System Forensics

**Pilot preview.** Lab 2 is complete and tested in CI and on macOS. It has not yet been used in a class.

### For students
- New lab: [Lab 2 — Linux File-System Forensics and Evidence Examination](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab2-filesystem-forensics/docs/student-guide.md). It continues the Lab 1 incident: examine the compromised Cedarwick workstation's disk and the USB stick found in it, find how the malware arrived and persisted, and recover the deleted data, with The Sleuth Kit in an isolated container.
- Complete [Lab 0](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab0-orientation/docs/student-guide.md) and [Lab 1](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab1-network-traffic/docs/student-guide.md) first.

```bash
git pull        # or clone https://github.com/KernalGuard/cyberlab-platform.git
cd cyberlab-platform/labs/lab2-filesystem-forensics
docker compose pull
docker compose run --rm verify
```

### Known issue
Sleuth Kit tools crash on exit when reading `.E01` files directly in this image (library bug). The guide has students export verified raw working copies first.

### Tested
- GitHub Actions: Lab 0, 1 and 2 integration tests on amd64 and arm64.
- macOS Apple Silicon, Docker Desktop.
- **Not yet tested:** Windows (WSL 2), student walkthroughs.

All evidence is synthetic and the "malware" is inert text. Instructors: the Lab 2 generator, answer keys and rubric are in the private instructor repository. Details in [CHANGELOG.md](https://github.com/KernalGuard/cyberlab-platform/blob/main/CHANGELOG.md).
