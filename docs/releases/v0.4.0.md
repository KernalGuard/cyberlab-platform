## CyberLab v0.4.0 — Lab 3: Web Application Security Assessment

**Pilot preview.** Lab 3 is complete and tested in CI and on macOS. It has not yet been used in a class.

### For students
- New lab: [Lab 3 — Web Application Security Assessment](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab3-webapp-assessment/docs/student-guide.md). After the Lab 1–2 incident, Cedarwick Neighborhood Aid wants its donation website tested before relaunch. You run an authorised assessment of a lab copy that exists only on your computer, find and validate the weaknesses, fix one and prove the fix.
- Complete [Lab 0](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab0-orientation/docs/student-guide.md) first; Labs 1 and 2 give the story background.

```bash
git pull        # or clone https://github.com/KernalGuard/cyberlab-platform.git
cd cyberlab-platform/labs/lab3-webapp-assessment
docker compose pull
# sign work/authorized-use.md first
docker compose up -d
docker compose run --rm verify
```

### Safety
The Lab 3 site is **intentionally vulnerable**. It listens only on `127.0.0.1:8080`, its app and database have no internet route, and the lab will not report ready until you sign the authorised-use agreement. Never change the port binding or use these techniques on systems you are not authorised to test.
