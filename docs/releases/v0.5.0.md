## CyberLab v0.5.0 — Lab 4: Incident Response and Multi-Source Digital Forensics

**Pilot preview.** Lab 4 is complete and tested in CI and on macOS. It has not yet been used in a class. With it, all five planned labs (0–4) are available.

### For students
- New lab: [Lab 4 — Incident Response and Multi-Source Digital Forensics](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab4-incident-response/docs/student-guide.md). Cedarwick's donation site has been breached after its relaunch. Lead the investigation across site logs, an office network capture, a staff laptop image, the server's login log and a database snapshot: how the attacker got in, what was exposed, whether they are still in, and what Cedarwick must do now.
- Complete [Lab 0](https://github.com/KernalGuard/cyberlab-platform/blob/main/labs/lab0-orientation/docs/student-guide.md) first; Labs 1–3 provide the skills and the story.

```bash
git pull        # or clone https://github.com/KernalGuard/cyberlab-platform.git
cd cyberlab-platform/labs/lab4-incident-response
docker compose pull
docker compose run --rm verify
```
