# Student Setup

Do these **before your first lab session**: installing Docker can take 20–40 minutes and may need a restart.

1. Check your computer against the [pre-flight checklist](preflight-checklist.md).
2. Install Docker for your operating system:
   - [macOS (Apple Silicon or Intel)](install-macos.md)
   - [Windows 10/11 (WSL 2)](install-windows.md)
   - [Linux](install-linux.md)
3. Complete [Lab 0](../../labs/lab0-orientation/docs/student-guide.md).
4. Then continue with the lab your instructor assigns, for example [Lab 1](../../labs/lab1-network-traffic/docs/student-guide.md).

**Can't install Docker?** (Chromebook, locked-down computer, not enough memory.) Tell your instructor in the first week. A browser-based option is being prepared.

*Status: draft, 2026-10-09. These steps have not yet been walked through on student machines. Report anything confusing to your instructor.*
