# Pre-flight Checklist (5 minutes)

Tick every box before Lab 0. If you can't, contact your instructor **now**, not on lab day.

- [ ] **Operating system:** macOS (recent release), Windows 10 22H2 or Windows 11, or a current Linux distribution.
- [ ] **Memory:** at least **8 GB RAM**.
  - macOS:  → About This Mac. Windows: Settings → System → About. Linux: `free -h`.
- [ ] **Disk:** at least **20 GB free**.
- [ ] **Administrator rights:** you can install software on this computer.
- [ ] **Windows only — virtualization enabled:** Task Manager → Performance → CPU shows **Virtualization: Enabled**. If it says Disabled, it must be switched on in the computer's BIOS/UEFI settings (search for your laptop model + "enable virtualization").
- [ ] **Internet:** a connection that can download about 1 GB (home Wi-Fi is best; some public networks block Docker downloads).
- [ ] **Terminal:** you know how to open Terminal (macOS), Ubuntu/WSL (Windows) or a terminal (Linux).

When every box is ticked, follow the install guide for your system.
